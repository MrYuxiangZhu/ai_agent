# RAG 知识库系统说明

RAG 是 Retrieval-Augmented Generation 的缩写，即检索增强生成。它通过先从知识库检索相关资料，再把资料作为上下文交给大语言模型生成答案，从而降低幻觉并提升答案的可溯源性。

## 核心模块

一个完整的 RAG 系统通常包含文档导入、清洗解析、Chunk 切分、Embedding 向量化、向量库索引、关键词索引、混合检索、Rerank、上下文组装、LLM 生成、引用溯源和离线评估。

## 提高质量的方法

提高 RAG 质量的关键是数据质量、合理切分、混合检索、强 rerank、清晰 prompt 和持续评估。只使用向量检索通常不够，因为精确术语、编号、错误码和专有名词更适合 BM25 关键词检索。

## 引用溯源

高质量 RAG 回答必须提供引用来源。引用中应该包含文档来源、标题、chunk ID 和原文片段，方便用户确认答案是否被知识库支持。
